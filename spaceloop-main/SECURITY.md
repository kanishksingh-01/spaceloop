# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 2.4.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability
We take security vulnerabilities seriously, especially concerning:
- **DPDP Act 2023 Section 8 Compliance**: Guaranteeing zero raw 12-digit Aadhaar storage.
- **Financial & Escrow Integrity**: Server-side recomputation preventing client price manipulation.
- **Physical Access Security**: Tamper-proof cryptographic room QR verification and GPS geofencing.

To report a vulnerability, please open a security report via GitHub or email:
`security@spaceloop.in`

Please include reproducible steps and allow 48 hours for a coordinated disclosure response.
