# System Overview
SpaceLoop transforms underutilized urban spaces into affordable, verified study and project pods (₹40–₹75/hour).
It achieves this by replacing ₹15,000–₹25,000 IoT smart locks with a pure Zero-Hardware India Stack:
- ₹5 Printable Door QR Pass
- Live GPS Haversine Geofencing (<50m radar)
- Dynamic 4-Digit Caretaker / Keybox PIN
- AI Visual Condition Diff & Appliance Off Verification
- Instant ₹100 UPI Micro-Escrow Refund Protocol
- Section 52 Indian Easements Act Revocable Micro-Lease Synthesis
