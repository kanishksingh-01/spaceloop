# Component Diagram (C4 Level 3)
Details the interactions between backend modules:
- `AuthModule`: Identity and session context
- `SpacesModule`: Listings, dimensions, and amenities
- `DiscoveryModule`: Natural language semantic matcher
- `BookingsModule`: Reservation state machine
- `LeasesModule`: Section 52 revocable license generator
- `PaymentsModule`: ₹100 micro-escrow hold and instant refund
- `VerificationModule`: Dual-sided DigiLocker and Discom verification
- `AccessModule`: Haversine GPS radar and QR token validator
