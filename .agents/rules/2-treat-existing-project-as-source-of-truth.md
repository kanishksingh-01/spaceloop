# 2. Treat Existing Project as Source of Truth

## Inspection Requirement
Before making changes, inspect the existing code, project structure, README, and documentation.

## Preservation Principle
Preserve existing architectural and product decisions unless there is a clear technical reason to change them or the user explicitly requests a change.

## No Unnecessary Rewrites
Do not rewrite working components unnecessarily.
