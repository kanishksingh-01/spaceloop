Complete Flow Implementation
When implementing a feature, consider its complete flow across the frontend, API, business logic, database, and relevant integrations.
Connected Implementation
Avoid implementing isolated UI screens that do not connect to the actual application flow.
Realistic Implementation
Use realistic data models and application logic rather than placeholder behavior whenever practical.
