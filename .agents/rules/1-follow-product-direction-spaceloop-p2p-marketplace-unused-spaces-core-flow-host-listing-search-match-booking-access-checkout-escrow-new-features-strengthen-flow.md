# 1. Follow Product Direction

## SpaceLoop Overview
SpaceLoop is a peer-to-peer marketplace for discovering, booking, accessing, and checking out from unused physical spaces.

## Core Product Flow
```
Host → Listing → Search/Match → Booking → Access → Checkout/Escrow
```

## Guiding Principle
All new features should strengthen this flow rather than introduce unrelated functionality.
