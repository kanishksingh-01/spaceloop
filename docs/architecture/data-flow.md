# Data Flow Architecture
1. Host submits photo & notes -> Multimodal Inspector extracts specs -> Space persisted.
2. Seeker submits natural language query -> Semantic matchmaker ranks spaces.
3. Booking initiated -> Server validates positive bounds -> Synthesizes Section 52 lease -> Escrow held.
4. Arrival -> GPS radar <50m verified + Door QR scanned -> Caretaker PIN released.
5. Departure -> Walkthrough photo captured -> CV diff confirms appliances off -> ₹100 UPI refunded.
